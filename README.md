# Network City — Learn Networking by Building a City

A single-page, gamified learning app that teaches computer networking concepts through the metaphor of building and running a city. No build step, no dependencies — just open `index.html` in a browser.

## How to run

Open `index.html` directly in a browser, or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## What it covers

Levels are grouped into worlds, progressing from networking basics to cloud infrastructure:

- What Is a Network?
- IP Addresses & MAC Addresses
- How Data Travels: Packets
- Ports & Protocols
- TCP vs UDP
- Binary & CIDR
- Public vs Private IPs & NAT
- Choosing IP Ranges
- Subnets
- Routing & Route Tables
- DNS — The Phone Book
- DHCP — City Hall Hands Out Addresses
- VPC — Your Private City in the Cloud
- Security Groups & Network ACLs
- VPC Peering & Beyond
- Load Balancers & The Big Picture
- Final Boss: City Architect

## Tech

Plain HTML, CSS, and JavaScript in a single file — no frameworks or build tools required.
